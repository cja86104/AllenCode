# This file lives at https://www.allencodeco.com/robots.txt and is the
# first thing every search engine and crawler requests when discovering
# the site. Two rule blocks below:
#
#   1. Wildcard (*) — applies to every crawler that does not have its
#      own block. The site is fully crawlable except /preview, an
#      unlinked development route for the redesign (removed in its Phase 5). This
#      is correct because Allen Code Co is a public marketing site with
#      zero authenticated surface, no per-user pages, and no API routes.
#
#   2. Bingbot — explicit duplicate of the wildcard rules. Bing's
#      diagnostic tools have historically flagged sites that lack a
#      Bingbot-specific block as ambiguously configured. This block
#      removes that ambiguity and is the explicit fix for Bing's
#      "blocked from web" warning.
#
# Sitemap reference at the bottom points crawlers at the canonical
# sitemap. As of 2026-08-24 the app uses BrowserRouter (not HashRouter)
# with a Vercel rewrite for client-side routes, so every real page is a
# genuine, separately fetchable URL and the sitemap lists all of them —
# see the comment block in sitemap.xml for what's listed and why.
